# 🐶 Welcome to the Paw-some Side of Technology

> **Humane Pet Adoption Portal** is a Spring Boot REST API created to organize the
> world of pet adoption — from adorable pets and shelters to adopters and health
> records.

Instead of keeping pet information scattered across different places, this project
brings everything together through a clean and structured backend system.

# 🎨 The Paw-some Feature Wall

| 🐾 | Feature | Description |
|:---:|---|---|
| 🐕 | **Pet Management** | Create, view, update and remove pet information |
| 🏠 | **Shelter Management** | Maintain shelter details and pet associations |
| 👤 | **User Management** | Manage users and their pet relationships |
| 🩺 | **Health Records** | Store and manage important pet health information |
| 🔄 | **CRUD Operations** | Complete Create, Read, Update and Delete functionality |
| 🔗 | **Entity Relationships** | Connect pets, users, shelters and health records |
| 🛡️ | **Exception Handling** | Handle missing resources and invalid requests |
| 📖 | **Swagger Docs** | Explore and test APIs directly in the browser |
| 📝 | **Logging** | Monitor application activity through logging |
